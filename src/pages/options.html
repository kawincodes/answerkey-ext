Welcome to AnswerKey

  1. Paste your Anthropic API key below and click Save key.
  2. Reload any tabs that were already open, so the “Ask Claude” button can appear there.
  3. Select text on a page and click Ask Claude, or right-click it and choose Ask Claude.

Anthropic API key

AnswerKey talks to Claude with your own API key, so usage is billed to your Anthropic account. Create a key in the Claude Console.

The key is stored only in this browser profile (it doesn't sync to other devices), can't be read by web pages, and is sent only to api.anthropic.com.

    What gets sent

    Only when you ask a question, AnswerKey sends the selected text (plus the page title and site name, if enabled above) and your follow-up messages to Anthropic's API using your key. Nothing is sent anywhere else, and nothing is collected by the extension's author.
